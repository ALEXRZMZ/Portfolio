Mi portfolio web - un espacio para documentar mi evolución y abrir la puerta a nuevos proyectos.

Con este proyecto busco documentar mi evolución en el diseño gráfico, el diseño UX/UI y el diseño web.

La web funciona también como vía de contacto para trabajos y proyectos. Está desarrollada con HTML, CSS y JavaScript nativo como proyecto final del Máster en Diseño UX/UI y Diseño Web de CEI.

02

El reto

El problema a resolver

Necesitaba una web propia que reuniese mis proyectos y que yo mismo pudiese construir de principio a fin, sin plantillas ni librerías.

  • 1. PROBLEMA O RETO

    Diseñar y programar una web completa, adaptable a cualquier pantalla y con módulos de JavaScript propios.

  • 2. RESTRICCIONES

    Solo HTML, CSS y JavaScript nativo, sin librerías, con la fecha de la convocatoria y compaginándolo con mi trabajo y el poco tiempo personal disponible.

  • 3. APRENDIZAJE

    La mayor dificultad ha sido JavaScript: cada módulo lo he escrito yo, entendiendo cada línea antes de pasar a la siguiente.

Caso de estudio

Las piezas del sistema

  • Tipografías

    Climate Crisis para los titulares, con mucha personalidad, y Outfit para los textos, limpia y legible. Ambas se cargan desde Google Fonts.

  • Paleta de color

    Negro #1E1E1E, blanco #EEEDF6, verde #5CF87D como color de acento y gris #454545, definidos como variables CSS.

  • Formulario de contacto

    El formulario está maquetado con una etiqueta en cada campo y no realiza ningún envío real, como pide el proyecto.

  • Plantilla de proyecto

    Las cinco páginas de proyecto comparten la misma estructura y una sola hoja de estilos, lo que facilita mantener y ampliar la web.

04

La solución

Hecho pieza a pieza

Decisiones de diseño

  1. 01

    Plantilla única para los proyectos: las mismas secciones y un solo CSS compartido.

  2. 02

    JavaScript nativo por módulos: menú, filtro de proyectos y lightbox, cada uno en su propio archivo.

  3. 03

    Imágenes optimizadas: WEBP con alternativa en JPG, carga diferida y SVG siempre que es posible.
